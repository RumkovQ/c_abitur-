I wrote this for my university work
But if you’re still interested in what it is, it’s code for building a console application written in C++11, designed to track university applicants.
For example, we’ve taken the BTEU PK university as a case study; if needed, you can modify the code yourself to suit your own university.
New objects are written and saved to a universal container (.dat), and subsequent changes are made to it.
My code can filter by age/faculty/scores, and you can also change the period of study for a specific specialty.
